# 极视云直播

这是一个更完整、更接近真实电视直播平台的前端演示版本，包含：

- 左侧频道列表
- 中间直播播放器
- 右侧源状态与收藏列表
- 节目单与主播状态统计
- 频道分类过滤与切台交互
- HLS/M3U8 播放示例

## 运行方式

```bash
cd /path/to/repo
python3 -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```

## 真实直播源接入方案

建议使用以下模式：

1. 后端维护 `频道表 + 流地址 + 源状态`。
2. 前端按分类加载频道列表。
3. 点击频道后切换对应 `m3u8/hls` 流地址。
4. 使用 `hls.js` 播放，后台可增加主源 / 备源 / 监控。

示例：

```javascript
if (Hls.isSupported()) {
  const hls = new Hls();
  hls.loadSource(streamUrl);
  hls.attachMedia(videoElement);
}
```

## 稳定源筛选建议

- 优先使用合法授权源
- 建议提供主源 + 备用源
- 采样健康检查：首帧时间、卡顿率、断流间隔
- 加入 CDN / 分发 / 缓存
- 统一跟踪播放成功率和切台成功率
