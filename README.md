# TV Live Demo

这是一个更接近真实电视直播产品的前端原型，用于演示：

- 直播首页/频道列表布局
- 电视端深色风格
- 可切换频道的 HLS/M3U8 示例播放器
- 支持节目单和实时状态信息

## 运行方式

```bash
cd /path/to/repo
python3 -m http.server 8000
```

然后在浏览器打开：

```text
http://localhost:8000
```

## 真实 HLS / M3U8 接入方案

推荐使用以下架构：

1. 后端维护频道信息表（频道名、流地址、分组、国家、状态、是否可用）
2. 前端拿到频道列表并渲染 UI
3. 播放器根据频道选择对应 M3U8/HLS 地址
4. 通过 `hls.js` 在浏览器中播放 HLS 流

示例前端代码：

```javascript
if (Hls.isSupported()) {
  const hls = new Hls();
  hls.loadSource(streamUrl);
  hls.attachMedia(videoElement);
}
```

## 稳定直播源筛选建议

- 优先使用有明确授权的官方流源或合法分发渠道
- 检查源地址是否为 HLS/M3U8 且支持持续稳定播放
- 对源进行健康检查：首帧成功率、卡顿率、重试次数
- 采用分层策略：主源 + 备源 + 备用 CDN
- 把频道状态切分为：在线 / 低延迟 / 维护 / 异常

## 生产环境注意事项

- 需要后端对接流地址管理服务
- 对流地址做缓存、鉴权、分发和异常回退
- 建议加入监控：播放失败、连接超时、切台计数
- 如需跑在真实部署环境，最好加上后台 API 与存储层

## 额外说明

这个版本是“演示型前端”，它能展示真实直播播放体验，但并不代表给出一个最终上线的完整商业直播平台；后续如果你愿意，我可以继续把它扩展成：
